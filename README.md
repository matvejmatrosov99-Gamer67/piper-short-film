# PIPER — Маленькая история большого океана

Адаптивный информационный сайт на русском языке о короткометражном анимационном фильме Pixar «Piper» (2016).

## Запуск
Откройте `index.html` в браузере. Сайт не требует сборки или установки зависимостей.

## Публикация
GitHub Actions автоматически публикует сайт в GitHub Pages при push в ветку `main`.

Сайт использует изображения Unsplash и шрифты Google Fonts, поэтому для их загрузки требуется интернет-соединение.
